# Minimal Skills List Design

Replace the animated Skills bento grid with a quiet editorial list. Preserve all localized skill content, but present each capability as a numbered row with a small category label, title, subtitle, description and individually spaced tag pills.

The layout uses thin dividers, generous vertical spacing and no decorative SVG, spotlight, glow, tilt or particle effects. Desktop and tablet rows use a narrow number column beside the content; mobile keeps the same hierarchy with tighter spacing and wrapping tags.
