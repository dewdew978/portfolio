# Pixel Orb Mascot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reusable animated Pixel Orb mascot to the Navbar and Hero.

**Architecture:** A focused `PixelOrb` React component renders accessible decorative SVG artwork and manages optional pointer tracking. A colocated stylesheet owns pixel-art rendering, idle/blink/particle animations, theme variants, responsive behavior, and reduced-motion fallbacks.

**Tech Stack:** React 18, SVG, CSS, Node test runner, Vite

**Spec:** `docs/superpowers/specs/2026-10-27-pixel-orb-design.md`

## Global Constraints

- Reuse one component in Navbar and Hero.
- Preserve the profile photo and existing navigation behavior.
- Add no dependencies.
- Respect `prefers-reduced-motion`.
- Do not stage `.claude/`.

## Review Focus

- The Navbar mascot must not crowd controls at 320px.
- Pointer tracking must remain decorative and never intercept clicks.
- The SVG must stay sharp at both compact and hero sizes.
- Reduced-motion users must see no repeated movement.
- Light and dark themes must preserve visible facial features.
